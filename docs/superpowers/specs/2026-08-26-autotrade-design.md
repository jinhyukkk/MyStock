# 자동매매 v1 (KIS 모의/실전) — 설계

2026-08-26. 승인된 설계 — 검증한 전략을 그대로 실행하는 반자동 파이프라인.
수익 보장 장치가 아니라 "검증 안 된 규칙·뇌동매매를 막는" 규율 장치다.

## 흐름

장 시작 전: 시세 갱신 → 전략 시그널 스캔(마지막 봉) → 주문 목록 생성
(진입=오늘 시장가 매수, 청산=손절·시그널 매도) → 리스크 게이트(engine과
동일: 1% 룰, 비중 20%, 계좌리스크 6%, 최대 7종목, 현금 한도) →
미리보기(plan) → 사용자가 버튼으로 실행(execute) → KIS 발송·원장 기록.

## 구성

- `kis.py` — KIS REST 클라이언트. 토큰(meta 캐시, 재발급 rate limit 대응),
  잔고, 현재가, 현금 시장가 주문. 모의/실전은 KIS_MODE 하나로 도메인·TR만
  전환. 키는 .env(.env.local)에만, 로그·응답에 싣지 않음.
- `autotrade.py` — settings(meta: autotrade_preset/params), plan(dry-run),
  execute. balance를 인자로 받아 네트워크 없이 테스트 가능.
- DB: `auto_positions`(손절선 보관 — 증권사에 없는 정보), `auto_orders`(원장).
- API: GET /api/autotrade/status(키 없어도 동작), PUT /settings,
  POST /plan, POST /execute(confirm=true 필수, 실전은 화면 confirm 추가).
- 화면 `/autotrade` — 모드 뱃지, 전략 설정, 오늘의 주문(계획→실행),
  자동 포지션, 주문 이력.

## 규칙 (백테스트와의 일치가 최우선)

- 진입: 마지막 봉 enter 신호 + 강도 내림차순, 시장가(신호 익일 시가 규칙의
  실전 등가). 계좌(KIS 잔고)에 이미 있는 종목은 매수 제외 — 수동 보유와
  비중이 겹치면 안 된다.
- 청산: 어제 저가 ≤ 손절선(low<=stop, engine과 동일) 또는 exit 신호.
  자동 포지션이 계좌에 없으면(수동 매도) 주문 대신 경고.
- entry_price는 직전 종가 근사 — 체결가 확정 조회는 다음 단계.

## v1 제외 (다음 단계)

미국 주식 자동주문, 장중 실시간 감시, 무인 스케줄 실행, 체결가 확정 조회,
자동매매 성과 리포트(백테스트 대비 실전 괴리 측정).
