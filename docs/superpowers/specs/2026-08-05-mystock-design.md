# MyStock — 개인용 투자관리 웹앱 설계 스펙

작성일: 2026-08-05
상태: 사용자 승인 완료 (인터뷰 기반)

## 1. 개요

종목별 매수/매도 시그널을 한눈에 파악할 수 있는 **개인용(단일 사용자) 로컬 웹앱**.
사용자는 투자 전문가가 아니므로, 복합 지표를 종합 점수와 한국어 근거 설명으로
알기 쉽게 제시하는 것이 핵심 가치다.

- 대상 시장: 한국 주식(KOSPI/KOSDAQ), 미국 주식(NYSE/NASDAQ), 암호화폐, ETF(국내외)
- 투자 스타일: 스윙(며칠~몇 주) + 중장기(몇 달~몇 년) 병행
- 데이터: 일봉/지연 시세로 충분 (실시간 불필요)
- 사용 환경: 사용자의 맥에서 로컬 실행, 브라우저 접속. 배포·로그인 없음
- 시그널 확인: 앱 접속 시 대시보드에서 확인 (푸시/메일 알림 없음)

## 2. 아키텍처

```
[FinanceDataReader]──┐
[yfinance]───────────┤   ┌─────────────┐    ┌──────────────┐
[Upbit 공개 API]─────┼──▶│ FastAPI 백엔드 │───▶│ React 프론트엔드 │
[CNN F&G / Alt.me]───┘   │  (Python)     │    │ (Vite 빌드,     │
                         │  SQLite 저장   │    │  FastAPI가 서빙) │
                         └─────────────┘    └──────────────┘
```

- **백엔드**: Python FastAPI. 데이터 수집, 지표 계산, 시그널 엔진, SQLite 저장.
- **프론트엔드**: React + Vite. 프로덕션 빌드 결과물을 FastAPI가 정적 서빙하여
  **명령어 하나로 전체 앱 실행** (`localhost` 단일 포트).
- **저장소**: SQLite 단일 파일. 시세 캐시, 보유/관심 종목, 매매 내역, 시그널 히스토리, 커스텀 룰.

### 데이터 소스 (전부 무료, API 키 불필요)

| 대상 | 소스 |
|---|---|
| 한국 주식/ETF 일봉 | FinanceDataReader |
| 미국 주식/ETF 일봉 | yfinance |
| 암호화폐 일봉 | Upbit 공개 REST API |
| VIX | yfinance (`^VIX`) |
| VKOSPI (한국) | FinanceDataReader 시도, 불안정 시 표시 생략 |
| 주식 공포탐욕지수 | CNN 공개 엔드포인트 |
| 크립토 공포탐욕지수 | Alternative.me 공식 API |
| 펀더멘털 (PER/PBR/배당/시총) | yfinance(미국), FinanceDataReader/네이버 스냅샷(한국) |

### 갱신 정책

- 앱 시작 시 1회 + 앱 실행 중 6시간 간격 백그라운드 자동 갱신 + 화면의 수동 새로고침 버튼.
- 시세는 SQLite에 캐시하여 재시작 시 재다운로드 최소화. 외부 소스 장애 시
  마지막 캐시 데이터로 동작하고 화면에 "데이터 기준 시각"을 표시한다.

## 3. 시그널 엔진

### 3.1 종합 스코어 방식

각 기술적 지표가 -100(강한 매도) ~ +100(강한 매수) 점수를 산출하고,
가중 합산해 **종합 점수**와 **5단계 등급**(강력매수/매수/중립/매도/강력매도)으로 표시한다.

사용 지표 (일봉 기준):
- 이동평균: SMA 20/60/120 배열 상태, 골든크로스/데드크로스
- RSI(14): 과매수/과매도
- MACD(12,26,9): 시그널선 교차, 히스토그램 방향
- 볼린저밴드(20,2): 밴드 위치, 밴드 폭
- 스토캐스틱(14,3,3): 과매수/과매도 교차
- 거래량: 20일 평균 대비 급증 여부
- 52주 고저 대비 현재가 위치

### 3.2 이중 관점 (스윙 / 중장기)

- **스윙 시그널**: 단기 지표(RSI, 스토캐스틱, MACD, SMA20/60, 볼린저) 가중 중심.
- **중장기 시그널**: 장기 추세(SMA60/120 배열, 52주 위치, 주봉 환산 추세) 가중 중심.
- 두 점수를 종목마다 나란히 표시한다.

### 3.3 시장 심리 레이어 (VIX·공포탐욕)

- VIX, CNN 공포탐욕지수, 크립토 공포탐욕지수를 수집해
  대시보드 상단에 **시장 심리 게이지**로 상시 표시.
- 개별 종목 종합 점수에 시장별 보정치로 반영:
  - 미국 주식/ETF ← VIX + CNN F&G
  - 한국 주식/ETF ← VKOSPI(가능 시) + CNN F&G(참고)
  - 암호화폐 ← 크립토 F&G
- 극단적 공포 구간의 매수 시그널에는 "역발상 매수 참고" 맥락을,
  극단적 탐욕 구간의 매수 시그널에는 신중 표시를 덧붙인다.

### 3.4 근거 설명

모든 시그널에 한국어 근거 설명을 붙인다.
예: "RSI 28로 과매도 구간, 20일선이 60일선을 상향 돌파(골든크로스), 거래량 20일 평균 대비 180%".

### 3.5 펀더멘털 (주식/ETF만)

PER, PBR, 배당수익률, 시가총액을 종목 상세에 참고 정보로 표시한다.
점수 합산에는 넣지 않는다(데이터 신뢰도·시장별 편차 문제). 순수 표시용.

### 3.6 커스텀 룰

- 종목별 목표가 / 손절가 설정 → 도달 시 대시보드 뱃지 알림.
- 보유 종목은 평단가 대비 ±N% 조건 지원.

### 3.7 시그널 히스토리

일별 시그널 산출 결과를 SQLite에 저장해 종목 상세에서 과거 시그널 추이를 확인할 수 있다.

## 4. 화면 구성

1. **대시보드**
   - 시장 심리 게이지 (VIX, 공포탐욕지수)
   - 오늘의 매수/매도 시그널 요약 (보유+관심 종목 중 등급 변화·강한 시그널)
   - 포트폴리오 총 평가액·총 손익
   - 커스텀 룰 도달 알림 뱃지
2. **종목 상세**
   - 캔들차트 + 이동평균/볼린저 오버레이, 보조지표(RSI/MACD) 차트
   - 스윙/중장기 종합 점수와 등급, 지표별 점수 분해, 한국어 근거 설명
   - 펀더멘털 참고 정보, 시그널 히스토리
3. **포트폴리오**
   - 매매 내역 직접 입력(매수/매도, 수량, 단가, 일자)
   - 보유 종목별 평단가·수익률·평가금액, 자산 배분 차트(시장별/종목별)
4. **워치리스트**
   - 종목 검색·등록(4개 시장 통합 검색), 시그널 등급 목록 뷰

공통: 앱 하단에 "본 시그널은 지표 기반 참고 정보이며 투자 자문이 아닙니다" 고지 상시 표시.

## 5. 범위 제외 (YAGNI)

- 증권사 계좌 연동, 자동 매매 주문
- 실시간/분봉 시세
- 클라우드 배포, 모바일 최적화, 로그인/멀티유저
- 이메일·메신저 알림
- 백테스팅

## 6. 에러 처리 원칙

- 외부 데이터 소스별 독립 실패 허용: 한 소스가 죽어도 나머지 시장은 정상 동작.
- 실패한 소스는 화면에 "갱신 실패 (마지막 데이터: 시각)" 배지로 표시.
- 상장폐지·심볼 변경 등으로 데이터가 없는 종목은 목록에 오류 상태로 표시하되 앱 전체는 정상 동작.

## 7. 테스트 전략

- 시그널 엔진(지표 계산·스코어링)은 고정된 시세 픽스처 기반 단위 테스트로 검증 (핵심).
- 데이터 수집 계층은 소스별 파서 단위 테스트 + 실제 API 스모크 테스트 분리.
- API 엔드포인트는 FastAPI TestClient로 통합 테스트.
