# 플로이팅 글래스 다크 UI 리디자인 설계

날짜: 2026-08-06
상태: 승인됨

## 목표

기존 스택(React 19 + Vite 8, 의존성 추가 없음)을 유지한 채 프론트엔드를
Linear·Vercel 풍 "플로이팅 글래스 다크" 룩으로 리디자인한다.
순수 프레젠테이션 레이어만 변경한다.

## 범위

### 1. 디자인 토큰 (theme.css)
- 배경: 딥 네이비 베이스 + 상단 좌우 라디얼 그라디언트 글로우(고정 배경)
- 카드: 반투명 배경 + backdrop-filter blur + 반투명 보더 + 그림자 (글래스)
- 액센트: 블루-바이올렛 그라디언트 (버튼·활성 탭·강조)
- 전역 tabular-nums, 폰트 렌더링 개선

### 2. 마이크로 인터랙션 (CSS만)
- 카드 호버 부상(translateY + 그림자), 페이지 진입 시 카드 스태거 페이드업
- 버튼 호버 글로우, 테이블 행 전환
- prefers-reduced-motion 존중

### 3. 컴포넌트 소폭 수정
- Layout: 스티키 글래스 헤더, 그라디언트 로고 텍스트, 활성 탭 그라디언트 필
- SentimentGauge: 게이지 호 그라디언트 스트로크
- ScoreBar: 그라디언트 필 + 채움 애니메이션
- SignalBadge: 반투명 글로우 링
- 로딩 문구 → 스켈레톤 시머

## 범위 외 (변경 금지)

API 클라이언트, 타입, 라우팅, 차트 로직, 백엔드 전체.

## 검증

- `npm run build` 통과
- 브라우저 프리뷰에서 4개 페이지(대시보드·상세·포트폴리오·워치리스트) 육안 확인
