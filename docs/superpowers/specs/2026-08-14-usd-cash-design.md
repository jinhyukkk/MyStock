# 달러 예수금 분리 관리 — 설계

날짜: 2026-08-14 · 상태: 승인됨

## 배경
예수금이 `meta.cash_krw` 단일 원화 필드라, 달러 예수금을 원화로 환산 합산해 넣으면
환율 변동이 총자산에 반영되지 않는다. 스프레드시트는 원화/달러 예수금을 분리 관리한다.

## 설계
- **저장**: `meta`에 `cash_usd` 키 추가. 스키마 변경 없음.
- **API**: `PUT /cash` 본문을 `{amount, amount_usd?}`로 확장. `amount_usd` 생략 시
  기존 값 유지(하위호환). `GET /portfolio` totals에 `cash_usd`, `cash_usd_krw` 추가.
- **계산**: `build_portfolio(..., cash_usd=0.0)` — 현재 환율(`usdkrw`, 폴백 1400)로
  환산해 현금·총자산·배분 차트("현금" = 원화 + 달러 환산 합계)에 합산.
- **화면**: 포트폴리오 예수금 입력란 옆 "달러 예수금 (USD)" 입력 추가.
  요약 줄: `현금 ₩X (₩A + $B)`.
- **이관**: 기존 합산 입력분 ₩100,523,320 → 원화 ₩52,672,427 + 달러 $33,923.21 분리.

## 테스트
- `build_portfolio` 달러 예수금 환산·현금 비중·배분 합산.
- `PUT /cash` 하위호환(amount만 전송) + amount_usd 저장.
