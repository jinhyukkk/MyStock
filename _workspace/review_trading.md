# MyStock 실전 매매 리뷰 — 액티브 트레이더 멘토 (화면 기반 리뷰)

검토일 2026-08-16 · 방식: 코드 미열람, 실행 중인 앱(mystock preview)을 직접 조작하여 화면만으로 평가
경로: 대시보드 → NVDA/SK하이닉스(000660)/NFLX 상세 → TradeDialog → 포트폴리오 → 워치리스트

매매 기록 폼은 열고 값까지 채워봤으나, 실제 사용자 계좌 원장을 변경하는 행위라
"기록" 버튼은 누르지 않음. 부분매도 후 숫자 정합성은 그래서 확인 불가로 남김.

## 1. 한 줄 판정

**조건부 Yes (신규 진입만).** 종목상세의 "행동 요약"은 진입가·손절·목표·수량·계좌 총
미결 리스크까지 화면에서 다 주지만, **보유 포지션을 정리할 때 필요한 숫자(실현손익·
청산 계획)가 화면에 아예 없어** 나가는 쪽 판단은 이 앱으로 못 한다.

## 3. 돈이 새는 지점 (Money Leak)

**ML-1. 강력매도 종목 화면이 "추가 매수 가능"만 알려준다 (P0)**
- 화면: `/ticker/NFLX` — 상단 스윙 **강력매도 -21**, 대시보드 평단 대비 **-25.46%**.
  그런데 행동 요약 4칸은 전부 매수용: 제안 손절가 $73.496, 제안 목표가 $87.489,
  **"이미 67 보유 → 추가 매수 가능 204.551"**.
- 손실 시나리오: 강력매도 신호에서 화면이 유일하게 제시하는 액션 숫자가
  "204주 더 살 수 있다"임. 그대로 100주 물타기 시 $7,816 추가 노출, 손절 $73.496
  터치 시 -$466, 평단은 더 내려가 원 포지션 청산 판단은 더 지연됨.
- 개선: 보유 종목·매도 등급일 때 행동 요약을 **청산 모드**로 전환 — "내 평단 $104.85
  / 현재 손절 라인 대비 위치 / 부분청산 1/3 시 회수 금액·실현손익" 3칸으로 교체.

**ML-2. 총자산 등락률의 분모가 총자산이 아니다 (P0)**
- 화면: 대시보드·포트폴리오 상단 "총자산 (평가액+예수금, KRW 환산)
  ₩178,851,703 / **₩-1,457,885 (-1.83%)**".
- 검증: 1,457,885 / 178,851,703 = **-0.81%**. -1.83%는 전일 평가액(₩79.7M) 기준값.
  현금 비중 56.2% 계좌에서 **체감 손실이 2.2배로 부풀려 표시**됨.
- 손실 시나리오: "하루 -1.83%"로 읽고 리스크 축소를 결심 → 실제 -0.81%인데 정상
  스윙 포지션을 조기 청산. 반대로 상승일엔 실력을 2배로 착각.
- 개선: 숫자 옆에 분모를 명시 — "평가액 기준 -1.83% · 총자산 기준 -0.81%" 두 값 병기.

**ML-3. 실현손익 화면이 존재하지 않는다 (P0)**
- 화면: 포트폴리오 전체를 훑어도 "실현", "누적 손익", "승률", "손익비" 항목 없음.
  보유 종목 표는 미실현 손익만, 매매내역 60행은 전부 "매수".
- 손실 시나리오: 내 실제 기대값을 모르는 채로 시그널 백테스트 승률(62%)만 믿게 됨.
  시스템이 돈을 벌고 있는지 여부를 화면에서 확인할 수단이 0.
- 개선: 포트폴리오 상단에 "실현손익(비용 차감 후) / 거래 수 / 승률 / 평균이익:평균손실
  / 최대연속손실" 카드 추가.

**ML-4. 매매내역에 인위적 "보정 로트"가 실거래와 섞여 있다 (P0)**
- 화면: 매매내역에 `2025-10-14 NFLX 매수 37 @ 33.27`, `2025-11-07 NFLX 매수 1 @
  1,132`, `2025-04-10 NVDA 매수 3 @ 5.54` — 메모에 "시트 평단 맞춤 보정 로트".
  평단($104.85)은 이 가짜 체결가 덕에 산술적으로만 맞음.
- 손실 시나리오: 이 원장으로 실현손익·승률을 계산하면 NFLX 37주는 $33.27 →
  $78.16, +135% 승리로 잡힘. 실제로는 액면분할 전 고가 매수분. 성과 복기가
  통째로 거짓이 됨.
- 개선: 보정 로트에 **"집계 제외" 배지**를 달고, 실현손익·승률 집계에서 제외됨을
  표 헤더에 고지. 분할(split) 조정 여부도 표에 열로 표시.

**ML-5. 백테스트 표에서 등급 서열이 무너져 있는데 요약 카드는 이를 숨긴다 (P1)**
- 화면: SK하이닉스 `/ticker/000660` 스윙 표 — **강력매수 5일 +0.27%(승률 48.6%,
  20일 손절률 51.4%)** vs **중립 5일 +1.65%(57.8%, 38.8%)**. NVDA 표에서도
  **매도 등급 5일 +2.46%(64.2%)가 매수 +1.5%(55.6%)보다 우수**, 전 등급 5일 평균이
  플러스(상승장 착시).
- 손실 시나리오: 상단 요약 카드는 "이 등급의 과거 성적(20일) 승률 62%"만 크게
  보여줌. 등급이 방향성을 못 가른다는 사실은 아래 표를 직접 읽어야만 보임 →
  무의미한 신호로 진입, 왕복 비용 0.19~0.23%p만 반복 지출.
- 개선: 요약 카드 옆에 **"등급 판별력" 배지** — 매수 등급 20일 성과 − 매도 등급
  20일 성과(스프레드)를 계산해 0 이하면 "이 종목에서 시그널은 방향을 가르지
  못함"을 붉게 표기.

**ML-6. 주문 입력창에 리스크가 하나도 없다 (P1)**
- 화면: `매매 기록` 다이얼로그 — 구분/수량/체결단가/체결일·시각/수수료·세금/메모가
  전부. 수량 10을 넣어도 **체결금액·추정 수수료·예수금 잔액 변화·이 주문의 계좌
  대비 리스크%가 표시되지 않음**. 매도로 전환해도 보유수량(25주)·평단($176.03)·
  예상 실현손익이 안 뜸.
- 손실 시나리오: 상세 화면의 "제안 수량 91.4주"를 봤어도 다이얼로그에서 손이
  미끄러져 200주를 넣으면 계좌 리스크 1% → 2.2%로 뛰는데 화면이 아무 말도 안 함.
  12종목이면 총 미결 리스크 상한 6%를 조용히 초과.
- 개선: 다이얼로그 하단에 실시간 요약 줄 — "체결금액 $2,251.60(₩3.18M) · 추정
  비용 $2.17 · 이 주문 후 종목 비중 6.1% / 계좌 총 미결 리스크 3.56% → 4.02%".

**ML-7. 제안 손절·수량이 실제 주문 규격과 맞지 않는다 (P2)**
- 화면: SK하이닉스 "제안 수량 **5.095**", "추가 매수 가능 **0.095**" — 국내주식
  소수점 주문 불가. 같은 화면 제안 손절가 **-21.34%**, 목표가 **+42.68%**
  (ATR 10.67%).
- 손실 시나리오: 스윙 화면이 21% 손절폭을 제시 → 실제로는 그 손절을 지킬
  트레이더가 없고, 결국 손절 없는 매매가 됨.
- 개선: 시장별 최소 주문 단위로 반올림해 정수 표시(+ "소수점 주문 미지원" 안내),
  ATR이 큰 종목은 "이 종목은 2×ATR 손절이 -21%라 스윙 타임프레임에 부적합" 경고.

**ML-8. 손익/수익률에 비용 차감 여부 라벨이 없다 (P2)**
- 화면: 포트폴리오 보유 종목 표의 "손익", "수익률" 열, 대시보드 "평단 대비" 열 —
  매도 시 발생할 수수료·증권거래세(KR 0.15%대)·환전 스프레드가 반영됐는지 표기
  없음. 매매내역 "비용" 열은 60행 전부 "추정"인데 **추정된 금액이 화면에 표시되지
  않음**.
- 손실 시나리오: KB금융 -0.13%를 "본전"으로 보고 청산 → 거래세·수수료 차감 후
  실제 -0.3%대 손실 확정. 국내주식 전량 정리 시 평가액 ₩28.6M × 0.18% ≈ ₩51,000이
  화면에 없던 비용.
- 개선: 열 헤더를 "손익(매도 비용 차감 전)"으로 바꾸고, 종목 행 확장 시 "지금
  전량 청산 시 순회수액" 표시. 매매내역 "추정"에 마우스 올리면 추정 금액 노출.

## 4. 화면 개선 제안

**P0**
1. 종목상세 행동 요약을 **보유/미보유 × 매수/매도 등급 4분면**으로 분기. 보유+매도
   등급이면 청산 카드(현재 손절 라인, 부분청산 시 실현손익, 손절까지 남은 %)로
   교체 — 지금은 강력매도 화면이 물타기를 권하는 모양새다.
2. 총자산 등락률에 분모 병기 — 현금 56% 계좌에서 손실 체감을 2배로 왜곡하면
   포지션 사이즈 판단이 통째로 틀어진다.
3. 포트폴리오 최상단에 **실현손익 요약 카드**(비용 차감 후 명시) — 시스템이 돈을
   벌고 있는지 화면에서 확인할 방법이 지금 없다.
4. 매매내역 "보정 로트"에 집계 제외 배지 — 가짜 체결가가 승률 통계에 섞이면
   복기 전체가 무의미해진다.

**P1**
5. 요약 카드에 "등급 판별력(매수−매도 스프레드)" 배지 — 승률 62%만 크게 보여주면
   그 62%가 중립 등급 50%와 다를 게 없다는 사실이 가려진다.
6. TradeDialog 하단 실시간 요약 줄(체결금액·추정비용·주문 후 비중·주문 후 계좌
   리스크) + 매도 시 보유수량/평단/예상 실현손익 — 사이징 계산이 상세 화면에만
   있고 주문 화면으로 승계되지 않으면 실전에서 안 쓰인다.
7. 상관계수 표에서 0.7 이상 셀 하이라이트 + "실질 클러스터 비중" 요약 — 최대
   종목 비중 9.3%로 안전해 보이지만 QQQ·TSM·NVDA·MU·BE가 0.44~0.75로 묶여 실질
   단일 베팅이다.

**P2**
8. 제안 수량 시장별 정수 반올림, ATR 과대 종목 타임프레임 부적합 경고.
9. 손익 열 라벨에 비용 기준 명시 + "지금 전량 청산 시 순회수액".
10. "체결 시 등급" 자동 기록 — 지금 전 행이 "—"라 시그널↔실거래 연결 복기가
    원천 불가.

## 6. 신뢰할 만한 부분

1. **백테스트 정직성** — 관측기간, 신호일수, 독립표본(비중첩 에피소드) 병기, 20개
   미만 칸은 수치를 감춤, 왕복 비용 차감 "순" 수치 병기, 중장기 구간은 "검증 불가"로
   못박고 "시간이 지나도 자동으로 채워지지 않습니다"까지 명시. 이 수준의 자기제한
   고지는 드물다.
2. **계좌 총 미결 리스크 화면** — 모든 보유가 2×ATR 손절에 닿았을 때 손실 합계
   3.56%(₩6,372,708) / 상한 6%를 종목별로 분해. 상세 페이지 상단에도 같은 값이
   따라붙어 진입 전 확인이 된다.
3. **시그널 근거 완전 노출 + 데이터 신선도 경고** — 지표별 점수·근거 문장이 표로
   다 보이고, 대시보드에 "기준: 8시간 전" 경고 배너가 뜬다. 목표가가 60일 고점
   위일 때 손익비 0.49:1로 재계산해 경고하는 것도 좋다. 콘솔 에러 0건, 실패
   네트워크 요청 0건.

## 7. 확인 불가 항목

- 부분매도 후 평단·실현손익 정합성 — 사용자 실계좌 원장을 변경하게 되므로 "기록"
  실행 안 함.
- 수수료·세금 "추정" 요율의 실제 값 — 화면에 금액이 표시되지 않음.
- 가격/RSI/MACD 차트의 렌더링 내용 — 캔버스라 텍스트 추출 불가, 스크롤 중
  스크린샷 캡처가 간헐적으로 빈 화면을 반환.
- "새로고침", "손절가를 룰로 등록", 커스텀 룰 등록 후 알림 동작 — 외부 시세
  호출/상태 변경이라 미실행.
- 평단이 매수 수수료를 포함하는지 여부 — 화면에 기준 표기 없음.
